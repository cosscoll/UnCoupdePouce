# Design UCP

Fichier éditable : https://www.figma.com/design/uq30FzP1RpEIUjmCkjHpYq

Écrans créés : tableau de bord demandeur, publication mobile, récapitulatif, découverte professionnel, messagerie, administration, profil professionnel. Composants réutilisables, variables et variantes exploratoires sont présents. Les sept écrans ont été inspectés visuellement dans Figma ; ce ne sont pas des tests de l'application dans un navigateur.

Identité appliquée : logo officiel fourni, orange #FF791D, violet #505DC1, beige #F5F0EA, vert #1A6B05, titres Anton et texte Montserrat. Les fichiers de polices et leurs licences OFL sont inclus ; aucun chargement Google Fonts externe au runtime. Seule la graisse Montserrat 400 est fournie ; les graisses supérieures sont synthétisées par le navigateur.

La limite du connecteur Figma a été atteinte. La dernière vue globale des composants et la capture après correction des explorations n'ont pas pu être vérifiées. Aucun abonnement ni crédit supplémentaire acheté. Les captures périmées ont été exclues de l'archive ; les quelques exports présents documentent les écrans vérifiés. Aucun prototype interactif Figma n'est annoncé comme application opérationnelle.
